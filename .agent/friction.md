# Журнал проблем и затруднений

## 2026-10-27 14:37 +03:00 — Сборка solution прерывается в параллельном режиме

- **Задача / контекст:** Проверка сборки после переноса приложения в `src/`.

- **Что произошло:** `dotnet build ... --no-restore` завершился сообщением MSB5021 о принудительном завершении `csc`, хотя ошибок компиляции не вывел.

- **Предпринятые попытки:** Повторная сборка с восстановлением пакетов и `-m:1`.

- **Решение:** Последовательная сборка завершилась успешно; причина первого прерывания не установлена.

- **Предполагаемая первопричина:** Возможная проблема параллельного запуска MSBuild в среде; подтверждений этому кроме единичного прерывания нет.

- **Предлагаемое улучшение:** При аналогичном сообщении повторить сборку с `-m:1` и проверить доступные ресурсы/состояние процессов.

## 2026-10-27 14:55 +03:00 — Не описана подготовка ключей Data Protection

- **Задача / контекст:** Переписать README с порядком локального запуска и OAuth-авторизации сервиса.

- **Что произошло:** В `Program.cs` отключена автоматическая генерация ключей Data Protection при защищённом хранении OAuth-токенов. В прежнем README это условие отсутствовало; в репозитории не найдена процедура подготовки ключей для нового Redis.

- **Предпринятые попытки:** Сопоставлены регистрация Data Protection и OAuth-хранилища, конфигурация приложения и существующая документация.

- **Решение:** В README описаны требование подготовленного набора ключей и discriminator приложения. Полная процедура первоначальной подготовки остаётся неизвестной.

- **Предполагаемая первопричина:** Возможно, ключи подготавливаются внешней инфраструктурой, порядок работы которой не отражён в репозитории.

- **Предлагаемое улучшение:** Описать источник ключей и воспроизводимую процедуру их подготовки для разработки и развёртывания.

## 2026-10-27 15:09 +03:00 — API Platform пришлось восстанавливать из сборки

- **Задача / контекст:** Заменить прямую интеграцию OpenTelemetry на `Texnokaktus.ProgOlymp.Platform`.

- **Что произошло:** В кешированном пакете Platform нет README и XML-документации, а nuspec не содержит URL исходников. Поиск версии через NuGet завершился отказом соединения с настроенным прокси `127.0.0.1:9`. Обычная reflection-загрузка методов также потребовала отсутствующие в контексте PowerShell зависимости.

- **Предпринятые попытки:** Изучены nuspec пакета и пример `UsePlatform()` в соседнем ResultService; затем метаданные и IL кешированной сборки прочитаны через уже установленный `Mono.Cecil`.

- **Решение:** Установлены API `ConfigureOpenTelemetry.WithTracerConfiguration`, обязательность `SERVICE_NAME` и встроенная настройка консольного Serilog. Использована кешированная версия `2026.9.19.2`; сборка solution прошла успешно.

- **Предполагаемая первопричина:** Пакет не поставляет документацию своего публичного API; ограниченная сеть затрудняет поиск дополнительных материалов.

- **Предлагаемое улучшение:** Добавить в пакет README, XML-документацию и ссылку на репозиторий с примером миграции, обязательными переменными окружения и перечнем настроек по умолчанию.
